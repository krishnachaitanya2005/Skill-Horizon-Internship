# Assignment 6 – DVWA on Kali Linux

## Objective
Installed and configured **Damn Vulnerable Web Application (DVWA)** on Kali Linux.  
Tested common web vulnerabilities at *Low, Medium,* and *High* security levels.  
Ran light automation tools for quick *fingerprinting and misconfiguration detection*.

## Tasks Performed
- Installed DVWA and started services.
- Set DVWA security to *Low, Medium, and High*.
- Performed vulnerability tests:
  - SQL Injection
  - XSS (Reflected)
  - Command Injection
  - File Upload / Unrestricted Upload
  - IDOR
  - Security Misconfigurations / Insecure Headers
  - Sensitive Info in Source / JS
  - Session Management Weaknesses
- Ran automation tools: `Nikto`, `WhatWeb`, `Dirb`, `Nuclei`.

## Outcome
Documented each vulnerability with payloads and screenshots.  
Saved scan outputs for report.  
Demonstrated how security level affects vulnerability exploitation in DVWA.
